# 视频口播通用规则

> 所有短视频文案技能的共享规则。每次生成口播脚本时必须遵守。

## 一、口播断句规则

每句话必须能一口气说完，否则观众听着累。

- 每句不超过 **25 个字**，超过必须断开
- 一句话里逗号超过 **3 个**，必须在合适位置改成句号或分段
- 断句方式：逗号改句号、长句拆成两段、删掉连接词让句子独立
- 断句后默读一遍，确保每句都能一口气说完
- **开篇前 3 句必须短**（≤15字/句），快速建立节奏

**示例：**

```
❌ 今天教大家用AI做封面，这个方法很简单，只需要3步，第一步打开工具...
✅ 两分钟做封面。AI直接生成。第一步，打开这个工具...
```

## 二、时长与字数对照表

中文口播语速约 **4 字/秒**，按此换算：

| 目标时长 | 口播字数 | 用途 |
|---------|---------|------|
| 30 秒 | 100-120 字 | 引流钩子、朋友圈视频、极简 Tips |
| 60 秒 | 220-260 字 | 干货速讲、观点速射 |
| 90 秒 | 340-380 字 | 标准教知识（互动率最高区间） |
| 3 分钟 | 680-760 字 | 方法论拆解、标准故事 |
| 5 分钟 | 1100-1200 字 | 深度教程、完整故事 |
| 8 分钟+ | 1800 字+ | 长教程/深度分析（需小高潮穿插） |

**时长建议（基于 39 条 S+A 级视频数据）：**
- 3-10 分钟是最安全区间（覆盖 80% 的爆款）
- 超过 10 分钟需要每 1-2 分钟制造一个小高潮维持注意力
- 内容密度 > 时长限制（24 分 36 秒的案例仍获 25 万赞）

## 三、前 3 秒钩子优先级（视频平台专属）

前 3 秒决定完播率。视频平台和公众号不同，不能靠文字扫描，必须用声音和画面瞬间抓住注意力。

| 优先级 | 钩子类型 | 使用率 | 适用内容 | 核心特征 |
|--------|---------|--------|---------|---------|
| ★★★★★ | AI 效果直接演示 | 38% | 教知识/追求更好 | 直接展示操作过程和结果，视觉冲击 |
| ★★★★ | 痛点连击+解决承诺 | 21% | 教知识/解决问题 | 3 秒内抛 2-3 个痛点，立刻给解决承诺 |
| ★★★★ | 震撼数据/权威反应 | 18% | 聊观点/丰富谈资 | 用具体数据或权威人物反应制造冲击 |
| ★★★ | 警告式颠覆认知 | 10% | 聊观点 | "90%的人都搞错了" |
| ★★★ | 场景还原/悬念反常 | 8% | 讲故事 | 用画面或声音还原一个反常场景 |
| ★★ | 全民喊话式 | 5% | 教知识 | "所有XX的人都应该知道" |

**视频号特有模式（姜胡说数据验证）：**
- 公式：【极小成本/极简动作】就可以【极大结果】。我不是在开玩笑，【真实性证据】。
- 核心：利益锚点 + 真实性强调 + 个人背书

**关键原则：**
- 开篇必须有明确的价值承诺（100% 覆盖率）
- 前 3 句必须短（≤15 字/句）
- 声音要高能量，不能平淡开场

## 四、互动设计（促进评论/分享）

每个视频最多使用 **1-2 个**互动设计，不能太多。

| 手法 | 使用位置 | 示例 | 效果 |
|------|---------|------|------|
| **请把 XX 打在公屏上** | 中间段完成关键步骤后 | "请把简单打在公屏上" | 提升评论率 |
| **资源福利引流** | 结尾 | "步骤都贴在评论区了" | 引导查看评论区 |
| **安全警示制造讨论** | 结尾前 | "注意假消息的风险" | 引发讨论 |
| **抛出问题等评论** | 结尾 | "你觉得呢？评论区告诉我" | 提升评论率 |

**使用原则：**
- "请把 XX 打在公屏上"要在用户完成某个操作后（有成就感时）使用
- 资源福利引流是最稳妥的方式（几乎适用所有视频）
- 视频号（姜胡说模式）：靠内容价值驱动转发，不靠钩子互动

## 五、结尾金句公式（10 条 S+A 级视频验证）

金句必须**独立成句**，前后留空隙（让观众消化）。

**公式 A：对仗式（S 级偏好）**
```
[旧范式]的时代结束了，[新范式]的时代开始了。
示例："手工作图的时代结束了，AI辅助创作的时代开始了。"
适用：技术革新类、观点输出类
```

**公式 B：让步转折式（A 级偏好）**
```
[工具/方法]可能不会[高期待]，但它确实能[实际价值]。
示例："AI可能不会完全取代你，但它确实能让你的效率提升十倍。"
适用：理性分析类、降低焦虑类
```

**公式 C：定义式（升华类）**
```
[工具/技术]的使命就是[释放/扩大][人的某种能力]。
示例："AI的使命就是释放人的创造力。"
适用：价值观输出类、升华类
```

**公式 D：不是A而是B（公众号爆款验证，视频版适配）**
```
[A]不是[表面理解]，而是[深层本质]。
示例："副业不是多打一份工，而是给自己多一条路。"
适用：观点类、认知颠覆类
```

## 六、数字与用词规则

### 数字中文化
口播稿中所有数字用中文表达：
- 100 → 一百
- 2026 → 二零二六
- 1万 → 一万
- 唯一例外：产品名中的数字保持原样（如 GPT-4）

### 载体词替换
- "这篇文章" → "这条视频"或"这个视频"
- "看完这篇文章" → "看完这条视频"

### 去双引号
- 口播稿中不使用双引号
- 用直接表述代替引用

### 禁止破折号
- 不使用"——"
- 用逗号、句号或分段代替

## 七、文案节奏通用模型（39 条视频验证）

### 段落结构
- **3 段式**：67% 的爆款使用 ← 最安全
- **4 段式**：31% 的爆款使用 ← 适合长教程
- **5 段式**：2% ← 不推荐

### 情绪曲线
```
高开（前3秒抓住注意力）
  ↓
平稳推进（建立信任，输出价值）
  ↓
小高潮穿插（每1-2分钟制造一个兴奋点）
  ↓
升华收尾（金句/行动召唤）
```

### 句式节奏特征
1. 开篇前 3 句必须短（≤15 字/句），快速建立节奏
2. 教学段落用"操作指令+效果描述"交替推进
3. 金句必须独立成句，前后留空隙
4. 短句连击只在情绪高点使用（开篇/高潮/转折）

### S 级 vs A 级差异
| 维度 | S 级 | A 级 |
|------|------|------|
| 情绪曲线 | 大起大落，有明显峰值 | 平稳上升，重在价值交付 |
| 时效性 | 热点 24 小时内发布 | 热点 1-3 天内发布 |
| 结尾 | 行动召唤（给出明确下一步） | 温和引导（收藏/关注） |

## 八、视频号平台特性（姜胡说 41 条数据验证）

### 人设公式
- 真诚分享 + 反割韭菜姿态
- 表达方式：口语化 + 即兴感（"想到哪儿说哪儿"）
- 信任基石：亲身经历 + 具体数字

### 论证铁律（93% 覆盖率）
- 亲身经历是信任基石（几乎每条都有"我""我当时""我的经历"）
- 具体数字提升可信度（30/41 条使用具体数字）
- 口语化表达+即兴感
- 对话感假设观众反驳（"很多人会说...""你可能觉得...但是..."）

### 结尾策略
- 总结号召是默认结尾（76%）：重申核心+极小行动+美好结果
- 金句升华是加分项（22%）
- 核心靠内容价值驱动转发，不靠钩子互动
